# Frontend formatting

`.prettierrc` matches the repo's style (single quotes, 4 spaces). Much of the existing code was hand-formatted rather than Prettier output, so format only files you create or substantially rewrite - running Prettier over the whole tree reflows lines in files you never touched.

## UI components and theming

Tailwind v4 (CSS-first: no `tailwind.config.js`, all theme tokens in `resources/css/app.css`, wired in through `@tailwindcss/vite`) plus shadcn/ui (Radix + Tailwind, copied into `resources/js/Components/ui/` - `components.json` configures it; add components with `npx shadcn@latest add <name>`). Run npm on the host, not Sail: `node_modules` holds macOS native binaries. Two things to know after every `shadcn add`: it writes `import { cn } from "cn"` (fix to `@/lib/utils`: `sed -i '' 's#from "cn"#from "@/lib/utils"#' resources/js/Components/ui/*.tsx`), and it can prompt to overwrite shared files (`--overwrite` is safe for ones you haven't edited - `card.tsx`, `badge.tsx` and `alert.tsx` are customized here: no flex/padding on `Card`, and `success|warning|danger|info` variants on `Badge`/`Alert`). `ui/` is generated style (double quotes, no semicolons) - don't Prettier it.

Theming is one place: `--surface`/`--box`/`--ink` in `:root`/`.dark` in `app.css`; the shadcn tokens (`--background`, `--card`, `--primary`, `--sidebar`...) are defined *in terms of* those, so shadcn components and the older plain `bg-white`/`text-gray-*` markup (repointed at the same variables in the `@layer utilities` block) always agree. New markup should use semantic tokens (`bg-background`, `bg-card`, `text-muted-foreground`, `bg-success`...), not gray/white. The old `Components/` atoms (`PrimaryButton`, `SecondaryButton`, `DangerButton`, `TextInput`, `InputLabel`, `Modal`, `Dropdown`, `SearchableSelect`, `FlashToast`) are kept as thin API-stable wrappers over shadcn (`Button`, `Input`, `Label`, `Dialog`, `DropdownMenu`, `Popover`+`Command`, Sonner) so call sites don't change; `Checkbox` is shadcn's directly (`onCheckedChange`, not `onChange`). Headless UI is gone. The authenticated shell is shadcn `Sidebar` (`AuthenticatedLayout.tsx`); the nav item arrays (feature gating, permissions) are unchanged from the old top nav.
